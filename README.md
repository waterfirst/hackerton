# 유리 패키징 TGV 품질 AX 해커톤 준비

> 실행계획 v0.2 · 2026-11-08  
> 공식 결과물은 업무혁신 기획서와 발표자료이며 구현은 선택입니다. 실제 배정 문제·팀 역할·데이터는 미확정입니다. 이 저장소는 실행 설계 문서와 공개 문헌에 연결된 학습용 시뮬레이터를 포함합니다. 실측 결과나 검증된 검사 제품은 아닙니다.

## 제안 주제

**현미경·편광 영상으로 TGV 홀 주변의 크랙 의심 부위를 찾고, 사람이 먼저 확인할 검토 순서를 제안하는 품질 AX 도구**

TGV(Through-Glass Via) 주변을 관찰한 현미경 영상의 결함 후보와 편광 관찰의 광학적 특징을 구분해 보여 주는 것을 목표로 합니다. 관측 신호만으로 크랙이나 잔류응력을 확정하지 않습니다.

## 우선순위

1. **현미경 영상 기반 크랙 후보 검출과 검토 화면**: 기본 과제.
2. **편광·복굴절 특징과 현미경 후보 비교**: 동일 위치 영상과 촬영 조건을 확보했을 때 확장.
3. **응력 시뮬레이션을 통한 가설 비교**: 물성·형상·경계조건의 출처를 확인할 수 있을 때만 별도 탐색.

편광 관찰이 유용한지는 실제 제공 데이터로 평가합니다. 응력 집중 예측, 복굴절 관측, 실제 크랙 라벨은 서로 다른 정보로 취급합니다.

허용된 영상 입력 → 홀 주변 관심영역 확인 → 크랙 후보 표시 → 확신 부족 사례 보류 → 사람이 검토 → 근거·판정 기록 내보내기

- 재배포 허가가 확인되지 않은 논문 그림, Adobe 문서의 기밀 그림, 원본 현미경 이미지는 올리지 않습니다.
- 비공개 저장소도 데이터 반입 승인을 대신하지 않습니다. 승인된 자료만 사용하고 출처·라이선스·허용 범위를 기록합니다.
- 이 초안의 평가 기준·일정은 제안입니다. 실험 성능, 참여자 역할, 행사 운영 확정 사항으로 인용하지 않습니다.

## React 연구 시뮬레이터

[공개 실험실 열기](https://waterfirst.github.io/hackerton/sim/)

- 6편 논문·5건 특허의 확인 범위와 가정을 각각 표시합니다.
- 10개 계산·개념 시나리오: 압축층 힘 평형, 가정한 완화곡선, Mode-I 균열 근방장, KI/KIC, 합성 깊이 산란, 기준 영역 차감, 공정 순서, Jones 광학, 양면 합성 영상, 두 빔 간섭.
- SID(P6)는 원문 미확보로 전용 계산을 제공하지 않습니다. 전체 정량 재현 검증 완료 건수는 0입니다.
- 슬라이더·수치 입력, 이전 곡선 비교, 접근 가능한 데이터 표, CSV와 조건·출처 JSON 저장을 지원합니다.
- 계산은 브라우저 내에서 수행하며, 원본 데이터 업로드·백엔드 해석기·분석 추적 코드는 없습니다.

### 개발과 배포

소스는 `simulator-src/`, GitHub Pages가 제공하는 정적 빌드는 `sim/`입니다. 기존 루트 `index.html`과 내장 GIF는 유지됩니다. `vite.config.js`의 base는 `/hackerton/sim/`입니다. 현재 Pages의 main 루트 배포 구성을 그대로 사용하며 별도 배포 워크플로를 추가하지 않습니다.

```sh
cd simulator-src
npm ci
npm test
npm run build
```

빌드한 `sim/index.html`, `sim/assets/`와 소스 변경을 함께 커밋해야 반영됩니다. 수치 모형은 `sim/models.js`, 불변량·단위·극단 조건 시험은 `sim/models.test.cjs`입니다. 테스트 통과는 수학적 일관성 검사이지 실험 재현 검증이 아닙니다.

실제 3D 열-구조 FEM, 이온 확산, 균열 성장, 정량 OCT 재구성은 별도 해석기·물성·경계조건·측정 데이터 검증이 필요합니다. 회로용 ngspice는 유리 응력 해석의 대체재가 아닙니다.


### Twin World (v1.1)

기존 문헌별 계산을 유지하고 Three.js 기반의 **설명용 디지털 모델** 작업대를 추가했습니다.

- 투명 유리의 단일 원형 홀, 실제 가로세로 비율, 전체/절반 단면, 홀 가공 깊이와 종횡비 표시.
- 강화층 → 블라인드 홀 → 관통 → 고체 Cu의 전체 체적 충전으로 이어지는 정규화 시연. 바닥부터 채워지는 형상은 지정된 진행값이며 레이저/도금 속도나 보이드를 예측하지 않습니다.
- P1의 두께·압축층·응력과 연결한 3D 직사각형 응력층, T1의 Kirsch·광탄성식과 연결한 고정 눈금 교차 편광 지도 및 관측점의 광학 지연·위상차.
- 1.00초 정규화 스토리보드: 0.00–0.18 강화층, 0.18–0.42 입구 가공, 0.42–0.62 깊이 가공, 0.62–0.72 관통 확인, 0.72–1.00 Cu 충전. 각 장면의 과정·방위각·고도각과 카메라 이동을 명시하고 클릭/스크럽으로 이동합니다.
- 장면별 카메라 경로, 재생/일시정지, 1×(1초)부터 0.05×(20초)까지 재생 속도, 시점·확대 버튼, 조건 JSON 저장. 카메라 드래그·시점 선택 시 자동 경로를 해제합니다. 1초는 실제 공정 시간이 아닙니다. OS 및 화면의 동작 줄이기 설정, 화면 밖/숨긴 탭의 애니메이션 중지.
- WebGL 생성 실패·컨텍스트 손실 시 계산을 유지하는 2D 단면/광학 지도. Three.js는 별도 지연 로드 청크이며 외부 CDN·분석 추적·실측 데이터 업로드가 없습니다.

광학 모드는 **빈 홀의 무한 평판** 해석해이며, Cu 충전 후 열팽창 불일치·잔류응력에 적용하지 않습니다. 응력층은 **홀 없는 평판**의 1D 힘 평형을 3D로 그린 것으로 유한요소해·확산 계산이 아닙니다. 센서 동기화, 물성 보정, 독립 실험 검증은 아직 없으며 검증된 디지털 트윈이나 크랙 발생/수율 예측 도구로 사용할 수 없습니다.

검증: 기존 9개 수치 시험과 신규 진행·형상·광학 단위 시험 6개 및 실제 3D 형상·카메라 경로 시험 13개, 11개 문헌 화면 전환, 입력 연동, 뒤로/앞으로 탐색, 390/768 px 반응형 화면 및 WebGL 실패 대체 화면을 확인했습니다. 제공된 QA 브라우저는 WebGL이 비활성화되어 GPU 기반 3D의 브라우저 실화면은 확인하지 못했습니다. 이 한계와 수학적 검사 통과를 실험 검증으로 혼동하지 않습니다.
