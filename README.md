## 제안 주제

**현미경·편광 영상으로 TGV 홀 주변의 크랙 의심 부위를 찾고, 사람이 먼저 확인할 검토 순서를 제안하는 품질 AX 도구**

TGV(Through-Glass Via) 주변을 관찰한 현미경 영상의 결함 후보와 편광 관찰의 광학적 특징을 구분해 보여 주는 것을 목표로 합니다. 관측 신호만으로 크랙이나 잔류응력을 확정하지 않습니다.

## 우선순위

1. **현미경 영상 기반 크랙 후보 검출과 검토 화면**: 기본 과제.
2. **편광·복굴절 특징과 현미경 후보 비교**: 동일 위치 영상과 촬영 조건을 확보했을 때 확장.
3. **응력 시뮬레이션을 통한 가설 비교**: 물성·형상·경계조건의 출처를 확인할 수 있을 때만 별도 탐색.

편광 관찰이 유용한지는 실제 제공 데이터로 평가합니다. 응력 집중 예측, 복굴절 관측, 실제 크랙 라벨은 서로 다른 정보로 취급합니다.

### 개발과 배포

소스는 `simulator-src/`, GitHub Pages가 제공하는 정적 빌드는 `sim/`입니다. 기존 루트 `index.html`과 내장 GIF는 유지됩니다. `vite.config.js`의 base는 `/hackerton/sim/`입니다. 현재 Pages의 main 루트 배포 구성을 그대로 사용하며 별도 배포 워크플로를 추가하지 않습니다.

```sh
cd simulator-src
npm ci
npm test
npm run build
```

빌드한 `sim/index.html`, `sim/assets/`와 소스 변경을 함께 커밋해야 반영됩니다. 수치 모형은 `sim/models.js`, 불변량·단위·극단 조건 시험은 `sim/models.test.cjs`입니다. 테스트 통과는 수학적 일관성 검사이지 실험 재현 검증이 아닙니다.

실제 3D 열-구조 FEM, 이온 확산, 균열 성장, 정량 OCT 재구성은 별도 해석기·물성·경계조건·측정 데이터 검증이 필요합니다. 회로용 ngspice는 유리 응력 해석의 대체재가 아닙니다.


### Twin World (v1.2)

기존 문헌별 계산을 유지하고 Three.js 기반의 **설명용 디지털 모델** 작업대를 추가했습니다.

- 투명 유리의 원형 홀 1–4개(4개는 가로/2×2), 공통 지름·벽 사이 간격 조절, 실제 가로세로 비율, 전체/절반 단면, 홀 가공 깊이와 종횡비 표시.
- 강화층 → 블라인드 홀 → 관통 → 고체 Cu의 전체 체적 충전으로 이어지는 정규화 시연. 바닥부터 채워지는 형상은 지정된 진행값이며 레이저/도금 속도나 보이드를 예측하지 않습니다.
- P1의 두께·압축층·응력과 연결한 3D 직사각형 응력층, T1의 Kirsch·광탄성식과 연결한 고정 눈금 교차 편광 지도 및 관측점의 광학 지연·위상차.
- 1.00초 정규화 스토리보드: 0.00–0.18 강화층, 0.18–0.42 입구 가공, 0.42–0.62 깊이 가공, 0.62–0.72 관통 확인, 0.72–1.00 Cu 충전. 각 장면의 과정·방위각·고도각과 카메라 이동을 명시하고 클릭/스크럽으로 이동합니다.
- 장면별 카메라 경로, 재생/일시정지, 1×(1초)부터 0.05×(20초)까지 재생 속도, 시점·확대 버튼, 조건 JSON 저장. 카메라 드래그·시점 선택 시 자동 경로를 해제합니다. 1초는 실제 공정 시간이 아닙니다. OS 및 화면의 동작 줄이기 설정, 화면 밖/숨긴 탭의 애니메이션 중지.
- WebGL 생성 실패·컨텍스트 손실 시 계산을 유지하는 2D 단면/광학 지도. Three.js는 별도 지연 로드 청크이며 외부 CDN·분석 추적·실측 데이터 업로드가 없습니다.

광학 모드는 **빈 홀의 무한 평판** 해석해이며, Cu 충전 후 열팽창 불일치·잔류응력에 적용하지 않습니다. 응력층은 **홀 없는 평판**의 1D 힘 평형을 3D로 그린 것으로 유한요소해·확산 계산이 아닙니다. 센서 동기화, 물성 보정, 독립 실험 검증은 아직 없으며 검증된 디지털 트윈이나 크랙 발생/수율 예측 도구로 사용할 수 없습니다.

검증: 기존 9개 수치 시험과 신규 진행·형상·광학 단위 시험 6개 및 실제 3D 형상·카메라 경로 시험 13개, 11개 문헌 화면 전환, 입력 연동, 뒤로/앞으로 탐색, 390/768 px 반응형 화면 및 WebGL 실패 대체 화면을 확인했습니다. 제공된 QA 브라우저는 WebGL이 비활성화되어 GPU 기반 3D의 브라우저 실화면은 확인하지 못했습니다. 이 한계와 수학적 검사 통과를 실험 검증으로 혼동하지 않습니다.

#### 홀 연결 성장 · 교차편광 노출과 국소 완화 (v1.4.0)

홀 개수 1–4개, 4개 가로/2×2 배열, 지름 D와 벽 사이 간격 g를 조절합니다. 가로 배열은 이웃 홀 사이 n−1개, 2×2는 가로·세로 네 흰 연결 경로를 사용합니다. 단일 홀에는 연결 크랙이 없습니다. 사용자 그림을 개념화한 지정 경로이며 실제 경로를 추적하거나 예측하지 않습니다. 원본 첨부 그림은 게시하지 않습니다.

**관찰과 가정을 분리합니다.** 크랙이 있는 위치에서 위상차가 높다는 관찰을 설명하기 위해 고위상차 띠와 좁은 중심부 완화를 따로 지정합니다. 띠를 크랙 경로에 미리 넣었으므로 위치 상관은 코드에 넣은 결과이고, 관찰의 진위를 검증한 증거가 아닙니다. 이전의 넓은 완화 가정도 버튼으로 비교할 수 있습니다. 두 가지 모두 미보정 개념 모델입니다.

- 기본장: 원형 홀 Kirsch 교란 중첩. 연결선까지 거리 d에서 텐서에 B=1+A exp[−(d/w)²]를 곱해 넓은 응력차 띠를 지정합니다. 기본값 A=1.5, w=0.22D이며 A=0이면 띠가 사라집니다. 경로와 띠는 에너지 해석이나 파괴역학으로 유도하지 않았습니다.
- 도달 후 국소 완화: 각 후보 경로의 최근접 투영 위치에 진행 끝이 도달한 시각 ta 이후, 텐서에 1−R(t−ta) exp[−(d/r)²]를 곱합니다. 아직 도달하지 않은 국소 영역은 해당 경로에서 완화하지 않고, 여러 경로의 영향은 합산 대신 최대 완화값을 씁니다. 기본 r=0.08D, R의 최대값0.8, 시간상수0.8s입니다. 좁은 크랙선 P가 완화되어도 주변 유리 Q는 같은 위치의 Kirsch 기준보다 높은 값을 남길 수 있습니다. 이는 지정한 가중치의 효과이지 측정된 잔류응력이나 평형해가 아닙니다. 이전 비교값은 A=0, r=0.3D입니다.
- 완성된 연결의 끝점은 홀 테두리이므로 자유롭게 진행 중인 균열 선단의 Mode-I 집중식을 적용하지 않습니다. 실제 균열면 경계조건, 홀 접합부 집중, 물성 기반 성장, 힘 평형·응력 재분배는 풀지 않습니다. 이동 끝에도 자유 선단 특이장을 넣지 않습니다. 법선·전단 응력이 없는 이상적 균열면과 광로상 주응력차가 모두0인 것은 서로 다릅니다.
- 목표 응력은 σ=추가하중+κE(500µm/t)ᵖ로 지정합니다. 실제 레이저 열흡수·열전달·열응력이 아닙니다. 레이저 항이 지배할 때 에너지 증가·두께 감소가 문턱 도달을 앞당기지만, 추가하중이 지배하면 광학 경로 감소 효과로 반대일 수 있습니다. 모든 홀에 공통 조건을 적용합니다.
- 에너지를 최대4초 시연 램프로 올리다가 지정 연결 경로상 최대Γ가 문턱에 이르면 하중을 고정하고 각 후보 경로의 완화 전 Δσ 최대 표본에서 양쪽 끝으로 진행합니다. 경로별 구간 속도 가중치는 0.25+0.75×(구간 양끝 평균 Δσ/경로 최대 Δσ)이며, 마지막 끝이 설정 시간에 홀에 닿도록 경로별 정규화합니다. 시작점이 홀 테두리이면 한 끝만 진행합니다. 시연 진행 시간은 0.2–5초이며 물성 기반 성장 속도가 아닙니다. 개별 연결부의 독립 파괴를 계산하지 않습니다. 띠 가정의 변경은 문턱 도달 시점·고정 하중·색 눈금을 다시 계산합니다. 따라서 프리셋·배율 변경은 세 지도 전환과 달리 동일 하중 비교가 아니며, A가 커져도 하중이 더 일찍 고정되어 표시되는 절대 Γ는 낮아질 수 있습니다.
- 지도는 기본 **교차편광 강도**와 위상차 δ(rad), 광학 지연 Γ(nm), 주응력차 Δσ(MPa), 교차 편광 강도를 제공합니다. 같은 조건의 모든 시간과 비교 지도에서 고정된 색 눈금을 사용합니다. 상한 초과는 포화될 수 있고 엄밀한 영역 최댓값이 아닙니다.
- **현재·완화 적용 / 같은 하중·완화 없음 / 같은 하중·Kirsch만**을 전환합니다. 세 지도는 같은 시간·같은 하중이며, 참조 지도는 발생 전 사진이 아니라 그 하중에서 가정을 제거한 가상 비교입니다. 발생 순간/완화 후 단계로 측정 시점의 차이도 따로 살펴봅니다.
- P는 연결 경로 문턱점, Q는 P 가까운 주변 유리의 고정 표본점입니다. P/Q 현재·참조·Kirsch 지연, 현재 주응력차, 시간곡선과 수치표를 제공합니다. Q는 전역 최대값이 아니며 모든 조건에서 P보다 높다고 보장하지 않습니다.
- 큰 Γ는 동일한 C·두께·주축 조건에서 큰 주응력차에 대응하며 **절대 응력의 직접 측정이 아닙니다**. 실제 광로 적분, 축 회전, 2π 위상 감김을 주의해야 합니다. 표시δ는 감기지 않은 위상차이며 실제 장비의 위상 복원·해상도·픽셀 평균화·산란은 계산하지 않습니다. 교차 편광 밝기는 Γ에 단조 비례하지 않습니다.
- 보라 양방향 화살표는 slow axis, 짧은 금색 선은 fast axis, 굵은 흰 선은 현재 성장한 크랙 위치 주석, 주황 점은 이동 끝입니다. 이 주석은 빛샘이 아니며 숨길 수 있습니다. 두 축은 직교하고180°가 같은 축이며 C부호에 따라 교환됩니다. Γ<1nm에서는 축을 숨깁니다. 양의 스칼라 띠·완화는 축 방향을 바꾸지 않습니다.

실측 보정, 독립 실험 검증, 실제 균열면·선단장, Cu 충전 응력, 수명/파괴 예측은 포함하지 않습니다. 실제 판단에는 발생 전후 동일 시편의 보정된 위상차·두께·C·균열 위치와 측정 시점이 필요합니다.

### 교차편광 표시와 성장 시연의 제한

I/I₀=sin²(2θ)sin²(πΓ/λ)를 사용하며 I₀는 첫 편광자를 지난 광량, θ는 fast axis와 편광자 각도의 차이입니다. 분석기는 편광자와 90°이고 단색 이상 광학입니다. θ=45°에서 Γ=λ/2는 밝고 Γ=λ에서는 다시 소광합니다. 축이 나란하면 높은 Γ도 소광합니다. 따라서 “높은 위상차는 항상 밝다”로 바꾸지 않았습니다. 편광자·파장, P에서45°/0° 조건을 조절해 이를 비교합니다.

표시 흰색 기준은 기본 I/I₀=0.15이며 0.02–1 조절, 표시값은 clamp((I/I₀)/흰색기준,0,1)입니다. 실제0–1 눈금과 약한 빛샘 확대를 전환하고 실제 P/Q 투과율을 별도 표시합니다. 노출은 물리값·위상차·응력·성장 시점을 바꾸지 않으며 영투과를 밝게 만들지 않습니다. 다른 지도의 색 눈금 상한 배율도0.25–2로 조절하지만 시간·세 비교 지도 사이 자동 대비 변경은 없습니다. 상한 초과는 포화합니다.

“응력이 높은 곳으로 전파”는 **지정된 홀 연결 경로 안에서 높은 완화 전 주응력차 구간을 더 빠르게 통과하는 순서 가정**으로만 구현했습니다. 경로는 응력 벡터를 따라 새로 생성하지 않습니다. 높은 응력 방향과 실제 균열 방향의 관계는 인성·에너지 방출률·응력 텐서·경계조건을 포함한 파괴역학 해석이 필요합니다. 높은 Γ 띠는 성장 전부터 후보 경로 전체에 놓은 가정이므로 경로 일치를 검증하지 못합니다.

검증: 기존 수치9건 + Twin 모델/형상36건 + 균열·광학·성장26건 + 표시 노출3건, 총74건 통과. 소광·위상 주기성·영입력·고정 눈금·진행 끝 도달 시각·부분 연결 형상·홀 회피·도달 후 완화·종료 시각 오차를 검사했습니다. 브라우저에서 물리값을 유지하는 노출 전환, P축45°/0° 비교, 단계별0→50→100% 진행, 4홀2×2 완료·시간 되돌리기·단일 홀·동작 줄이기·390/768px 가로 넘침 없음을 확인했습니다. GPU3D 실화면은 재검증하지 않았으며 기존3D 형상 수치시험은 유지합니다. 수치 일관성 검사는 실측 검증이 아닙니다.
