> 2026-11-08 · 모든 항목은 아직 미완료인 제안 작업이다. 담당 코드는 역할 제안이며 실제 팀 합의 후 이름으로 바꾼다. 체크는 증거가 있을 때만 한다. 날짜는 [실행계획](EXECUTION_PLAN.md)의 내부 목표와 공식 일정을 구분한다.

## 5. 최종 점검

- [ ] 신청·참석·팀 역할의 실제 상태와 제안 상태를 구분했다.
- [ ] 공식 일정·형식·심사 기준을 최신 안내와 대조했다.
- [ ] 배정 문제에 맞춰 제목·업무·실험을 바꿨다.
- [ ] 모든 수치는 출처와 표본 또는 가정이 있고, 미측정을 0으로 쓰지 않았다.
- [ ] 현재 결함 검출과 미래 발생 예측을 구분했다.
- [ ] 순위가 낮은 항목도 검토 대상이며 보류·미검토량을 숨기지 않았다.
- [ ] 기밀·개인정보·재배포 불가 자료·접근키가 없다.
- [ ] 오류·보류·사람 책임·수동 복귀를 설명할 수 있다.
- [ ] 기획서·발표자료가 열리고 공식 제출을 확인했다.
