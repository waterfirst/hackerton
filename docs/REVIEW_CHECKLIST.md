# 제출·검토 체크리스트

이 문서는 기획 초안의 검토용이다. 체크되지 않은 항목을 완료 사실로 해석하지 않는다.

## 문제 공개 직후

- [ ] 공식 문제와 TGV 품질 검사 준비안의 적합성을 확인했다.
- [ ] 맞지 않는 범위는 축소하거나 다른 문제로 전환했다.
- [ ] 실제 팀 구성과 역할을 합의했다.
- [ ] 사용 가능 도구·인터넷·외부 API·모델 규정을 확인했다.

## 데이터 반입·공유 전

- [ ] 사용·학습·저장·발표·재배포 허용 범위를 각각 확인했다.
- [ ] 회사·고객·제품 식별자와 미공개 공정 정보를 제외했다.
- [ ] 원본 파일명·메타데이터·주석·경로·화면 캡처를 점검했다.
- [ ] 기밀 문서와 그림, 재배포 불가 논문 자료를 포함하지 않았다.
- [ ] 비공개 저장소 여부와 별개로 필요한 데이터 사용 승인을 확보했다.
- [ ] 합성 예제와 실제 데이터를 구분했다.

## 검증 전

- [ ] 후보 표시와 실제 크랙 확인의 라벨 기준을 구분했다.
- [ ] 동일 시료·홀·취득 묶음의 데이터 누수를 방지했다.
- [ ] 평가 단위·표본 수·매칭 기준·임계값 선택 방법을 기록했다.
- [ ] 판정 불가·정합 실패·저품질 영상 처리 방식을 정했다.
- [ ] 비교 기준선과 오류 사례를 준비했다.

## 발표 전

- [ ] 현미경 관측, 편광 특징, 응력 시뮬레이션을 구분해 표시했다.
- [ ] 검증되지 않은 점수를 크랙 확률로 표시하지 않았다.
- [ ] 성능 수치에 표본 수·분할 방식·실행 조건을 함께 적었다.
- [ ] 합성 시연을 실제 공정 검증으로 소개하지 않았다.
- [ ] 수율 개선·양산 적용·실제 응력 재현을 근거 없이 주장하지 않았다.
- [ ] 미확정 참여자·역할·행사 일정에 대한 약속을 넣지 않았다.
- [ ] 공개 자료의 출처와 재사용 권한을 확인했다.
- [ ] 실행 안내와 재현 가능 여부를 점검했다.

## 이 초안의 현재 상태

- 작성 완료: 문제 정의, 기술 우선순위, 데이터·평가 계획, 시연·운영 제안.
- 미완료: 구현, 데이터 확보·승인, 모델 학습, 성능 평가, 행사 공식 조건 확정.
